# CRM Copilot

部门工作台 → 客户与商机。把散落在邮件、会议、群聊、电话里的客户沟通收到一起，自动对上客户，生成客户摘要，找出商机风险并给出下一步建议。
客户、联系人、商机本身仍在业务系统（Java，`enterprise-business-hub` 的 crm 包）里；Copilot 只存“围绕客户发生的事”和分析结果。

## 收进来什么（只收员工主动给的）

| 来源 | 怎么进来 | 去重键 |
|---|---|---|
| 邮件 | 上传 .eml；或连接邮箱（IMAP，只读指定文件夹，默认“CRM”） | Message-ID（没有时用内容哈希） |
| 会议 | 上传 .ics（标题、时间、参会人、纪要、关联文档链接） | UID（+ RECURRENCE-ID） |
| 飞书 / 钉钉 | 给机器人发“保存到CRM：……”（或 `#CRM ……`） | 平台 + 消息 ID |
| 手工 | 时间线上记录电话纪要、跟进、报价、会议、待办 | — |

不读收件箱里的其他邮件，不读员工之间的私聊，发给机器人的普通对话也不会自动进 CRM。
邮件附件走现有的文档解析（`service/document_intake.py`：白名单 + 文件头校验 + 防压缩炸弹，不做图片 OCR）。
`customer_activity` 上 `(source_provider, external_source_id)` 唯一：同一封邮件转发几次、同步几次都只有一条。

## 自动关联客户（`service/crm/matching.py`）

优先级：明确指定 → 联系人邮箱完全一致（0.98）→ 手机号（0.95）→ 公司邮箱域名（0.92，公共邮箱不算）→ 公司名称 / 别名出现在标题或正文（0.90）→ 模糊匹配（封顶 0.85）。

- ≥ 0.90 自动关联；0.60～0.90 列出候选，销售在“客户沟通收集”里选；< 0.60 不关联。
- **模糊匹配永远不会自动落库。** 一封邮件里有几个客户的人时也让销售选。
- 销售指定客户后记下对应关系（外部参与人的邮箱、发件人的公司域名，存 `crm_customer_alias`），本部门其他待归属的活动立刻重新匹配，以后同样的来源直接对上。
- 本公司的邮箱域名（`CRM_INTERNAL_EMAIL_DOMAINS`，加上员工连接的邮箱域名）是同事，不用来关联、也不会被记成客户邮箱。

## 时间线、摘要、风险、建议（`service/crm/insights.py`）

- **时间线**：邮件、会议、群聊、电话纪要、报价、业务系统里的跟进记录、商机阶段变化（`crm_opportunity_snapshot` 记录每次变化）、已创建的待办，按时间排。
- **摘要**（`customer_summary_snapshot`）：增量更新——上一版摘要 + 之后的新活动 → 新摘要，没有新活动不调用模型；只用本部门、这个客户的数据。员工自己选模型（按数据外发策略检查）。
- **风险**（`crm_risk_finding`）：确定性规则——长时间未跟进、报价后无回复、成交日期临近但阶段没变、金额下降、多次延期、没有下一步、关键联系人缺失；选了模型时再从沟通原文里找预算不足、决策人未参与、竞争对手、能力不匹配、上线时间冲突。**每条风险都带证据**；模型给的证据必须是原文里逐字出现的话，引用不到原文的一律丢掉。同一风险只有一条记录，规则不再成立时自动解除。每天自动扫描一次（提醒规则 `crm_risk_scan`）。
- **下一步建议**（`crm_action_suggestion`）：销售选择“确认创建任务 / 修改后创建 / 忽略 / 稍后提醒”。确认后只在待办中心给自己建一条待办——**不修改商机，不联系客户**。同一来源只生成一条建议，忽略的不会再冒出来，稍后提醒的到时间再出现。

商机加了“预计成交日期”和“下一步”（Java V10 迁移），风险规则用它们判断。

## 接口

`/enterprise/crm-copilot/...`，见 `FasdtApi/crm_copilot.py` 顶部注释。权限：只有该部门的有效成员能用；客户是否属于这个部门由业务系统按调用者身份校验（不是本部门的客户返回 404）。

## 配置

| 变量 | 默认 | 说明 |
|---|---|---|
| `CRM_INTERNAL_EMAIL_DOMAINS` | 空 | 本公司邮箱域名，逗号分隔 |
| `CRM_RISK_STALE_DAYS` | 14 | 多少天没沟通算长时间未跟进 |
| `CRM_RISK_QUOTE_WAIT_DAYS` | 7 | 报价后多少天没回复算风险 |
| `CRM_RISK_CLOSE_WINDOW_DAYS` | 7 | 距预计成交日期多少天内算临近 |
| `CRM_RISK_STAGE_STALE_DAYS` | 14 | 阶段多少天没变算停滞 |
| `CRM_IMAP_TIMEOUT_SECONDS` | 20 | 连接邮箱的超时 |

测试：`tests/test_crm_copilot.py`（关联规则、邮件 / 日历解析、风险规则、去重、人工归属、摘要只用有权限的数据、建议不自动写入、聊天保存）；Java `CrmListEndpointsIntegrationTest`（联系人只返回本部门、商机计划字段）。
